# Model evaluation

`floodlens.ml.metrics.segmentation_metrics` calculates IoU, Dice/F1,
precision, and recall from predictions and labels. Toy tests verify the
calculation. A final report must identify the experiment, split, number of
pixels/samples, threshold, and model version.

No Kuro Siwo or real Sentinel metric has been generated in Phase 3. An
unlabeled Trishuli run, if later performed, must be reported as qualitative
Himalayan inference, never Himalayan accuracy.
